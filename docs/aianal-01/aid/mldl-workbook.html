머신러닝 vs 딥러닝, 무엇이 다를까요?

똑같은 점 데이터를 놓고, 사람이 특성을 직접 설계하는 머신러닝과 신경망이 스스로 특성을 찾아내는 딥러닝, 두 가지 방식을 나란히 체험하며 차이를 몸으로 느껴봐요.

STEP 2 · 머신러닝 방식

"중심으로부터 거리"라는 특성을 사람이 직접 만들어요

원래 좌표 (x, y) 대신, 각 점이 중심에서 얼마나 떨어져 있는지를 나타내는 새로운 숫자 r을 사람이 직접 계산해서 만들어요. 이제 숫자 하나(r)만 보고 기준값을 정해보세요.

사람이 설계한 특성: r = √(x² + y²) — 중심으로부터의 거리 예측 규칙: r > 기준값 → 바깥 고리, 아니면 → 안쪽

기준값(r):

안쪽(정답) 바깥 고리(정답) 기준값
사람이 "중심으로부터 거리"라는 특성을 고안해서 계산해주면, 숫자 하나(r)에 기준값 하나만 그어도 100% 정확하게 나눌 수 있어요. 다만 이 특성을 무엇으로 만들지는 사람이 직접 결정해야 했어요 — 이게 전통적인 머신러닝의 핵심이에요.

STEP 3 · 딥러닝 방식

원본 좌표 그대로, 신경망이 알아서 경계를 찾아요

이번엔 r 같은 사람이 만든 특성 없이, 원래 좌표(x, y)를 은닉층 뉴런 8개짜리 작은 신경망에 그대로 넣어요. "학습 시작"을 누르면 신경망이 경사하강법으로 스스로 경계를 찾아가는 과정을 볼 수 있어요.

입력 2개(x, y) → 은닉 뉴런 8개(ReLU) → 출력 1개(시그모이드) 아무도 "거리"라는 개념을 알려주지 않아요 — 좌표값 그대로 넣을 뿐이에요.

STEP 4 · 머신러닝 vs 딥러닝

같은 문제, 두 가지 다른 해결 방식

두 방식 모두 결국 100% 정확도에 도달했지만, 그 과정은 완전히 달라요. 무엇이 다른지 나란히 비교해볼게요.

머신러닝 파이프라인

원본 좌표 (x, y) → 사람이 r = √(x²+y²) 특성을 설계 → 기준값 하나로 나누는 아주 단순한 모델 → 정확도 100%

딥러닝 파이프라인

원본 좌표 (x, y) → 신경망이 스스로 은닉 뉴런 8개로 특성을 학습 → 층을 쌓아 자동으로 경계를 조합 → 정확도 100%
머신러닝은 사람이 문제에 맞는 특성(r)을 직접 고민해서 만들어줘야 해요 — 특성 설계가 정확도를 좌우해요. 딥러닝은 원본 데이터를 그대로 넣고 층을 충분히 쌓으면, 사람이 알려주지 않아도 신경망이 스스로 쓸모 있는 특성을 찾아내요. 그 대신 딥러닝은 더 많은 파라미터와 데이터, 계산이 필요해요.
