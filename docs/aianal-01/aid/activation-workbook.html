활성화 함수, 왜 꼭 있어야 할까요?

직선 하나로는 절대 나눌 수 없는 데이터를 직접 만져보면서, 신경망 층을 아무리 쌓아도 활성화 함수가 없으면 여전히 "직선 하나"에 불과하다는 사실을 4단계로 체험해요.

STEP 1 · 선 하나로 나눌 수 없는 데이터

직선을 움직여서 완벽하게 나눠보세요

파란 점과 노란 점이 대각선으로 서로 엇갈려 있어요(이런 배치를 XOR 패턴이라고 불러요). 각도와 위치를 슬라이더로 움직여서, 파란/노란 점을 완벽히 나눠보세요.

STEP 2 · 활성화 함수 없이 층 쌓기

층을 2개 쌓아도, 계산해보면 여전히 직선 하나

아래처럼 입력 2개 → 은닉 유닛 2개 → 출력 1개짜리 신경망을 만들었어요. 활성화 함수 없이(그냥 곱하고 더하기만) 두 층을 쌓으면 무슨 일이 벌어지는지 계산해볼게요.

은닉층 (활성화 없음): h1 = x1 + x2, h2 = x1 + x2 − 1 출력층: out = h1 − 2·h2 대입해서 풀면: out = (x1+x2) − 2(x1+x2−1) = −x1 − x2 + 2 → 두 층을 거쳤지만, 결국 x1·x2에 대한 "직선 하나"의 공식으로 합쳐져요.

이 직선은 1단계에서 손으로 움직여봤던 "직선 하나"와 성질이 완전히 같아요 — 아무리 층수를 늘려도, 활성화 함수가 없으면 결과는 항상 하나의 직선(선형 함수)으로 뭉쳐져요.

STEP 3 · ReLU 하나로 규칙을 꺾기

ReLU를 넣으면 규칙이 둘로 쪼개져요

같은 신경망에 ReLU(음수는 0으로) 활성화 함수만 추가해볼게요. h2 = ReLU(x1+x2−1)는 점선 아래에서는 0으로 뚝 끊기고, 위에서만 값을 가져요 — 이 "꺾임" 하나가 전체 규칙을 둘로 쪼개요.

점선 아래 (x1+x2 < 1, h2=0): out = x1 + x2 점선 위 (x1+x2 ≥ 1, h2 활성화): out = −x1 − x2 + 2 → 규칙이 두 개로 나뉘니까, "가운데는 노랑, 양 끝은 파랑" 같은 직선 하나로는 불가능한 규칙도 만들 수 있어요.

점선은 규칙이 바뀌는 "꺾이는 지점"(x1+x2=1)이에요.
